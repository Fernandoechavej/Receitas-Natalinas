Site de Receitas Pro Natal

Seja bem-vindo ao site do Projeto de Receitas de Natal. O objetivo deste projeto é desenvolver e aplicar as habilidades e os conhecimentos adquiridos em aula sobre HTML e CSS na criação de um site, desde a estruturação do layout da página utilizando tags até a aplicação de elementos visuais, como classes e cores. A proposta é criar um ambiente web agradável, responsivo e útil para todos os usuários.
